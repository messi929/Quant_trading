# V3.3 Profitability Engine — Development Checklist

**기반**: `docs/V3.3_DESIGN.md` (모듈 명세) + `docs/V3.3_ROADMAP.md` (일정) + `docs/V3.3_INTERFACES.md` (시그니처) + `docs/V3.3_AB_PLAN.md` (실험)
**역할**: 각 PR의 작업 항목·DoD(Definition of Done)·의존성·검증 체크리스트.
**Branch**: `feature/v3.3-phase1` (이 branch에서 모든 V3.3 작업)

---

## 사용 방법

각 PR을 시작할 때:
1. 해당 PR 섹션을 펼쳐 작업 항목 확인
2. **공통 invariant** 체크리스트 확인
3. 작업 진행 → DoD 모두 체크 후 commit
4. 회귀 hook 통과 확인 후 사용자에게 PR 보고

---

## 공통 Invariant (모든 PR 적용)

```
[ ] frozen dataclass 사용 (no mutation)
[ ] pure function (no hidden state)
[ ] feature flag OFF 시 V3.2.1 동작 보존 (parity)
[ ] live-backtest parity (동일 config → 동일 결과)
[ ] risk_exit는 어떤 경우에도 veto 안 됨
[ ] leverage 차단 (max_gross_exposure ≤ 1.00)
[ ] 손실 포지션 pyramid 차단
[ ] 회귀 테스트 통과 (CLAUDE.md PostToolUse hook)
[ ] 임계값 hardcoded 없음 (calibration 도출)
[ ] 새 모듈은 typing 완비 + loguru 로깅
[ ] 한 PR = 한 책임 (관련 없는 변경 섞지 않음)
```

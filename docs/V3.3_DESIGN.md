## 1. 설계 결정 (확정)

| 항목 | 결정 | 이유 |
|------|------|------|
| 위치 | `v3/` in-place 진화 | 기존 alpha_weights, regime, paper trade 14건 보존 |
| SignalGenerator | Wrap & Extend | 회귀 테스트 100% 재사용, 점진 마이그레이션 |

| Leverage | 거부 (`max_gross_exposure ≤ 1.00`) | conviction-or-cash 원칙 |
| Feature flag | 모든 신규 정책 OFF default | 검증 전 production 무영향 |

## 2. 핵심 데이터 흐름

### 2.1 V3.2.1 (현재)

```
OHLCV/Macro → Regime → Alpha → OpportunityScorer → EntryFilter → Sizer → TradeSignal
```

### 2.2 V3.3 (목표)

```
OHLCV / Macro / Vol Prediction
   ↓
RegimeDetectorV2
   ↓
DirectionalAlpha + ConvictionSource
   ↓
OpportunityScorer  ──→  raw_opportunity
   ↓
EdgeCalibrator     ──→  expected_return_5d, expected_mae_5d, win_probability_5d
   ↓
EdgeEngine         ──→  net_edge_5d (cost + risk 차감)
   ↓
EdgeTierSystem     ──→  S/A/B/C 등급
   ↓
Operational EntryFilter (운영 제약만 — 변경 없음)
   ↓
AllocationEngine   ──→  net_edge / risk 기반 weight
   ↓
[BookAction generation]
   ├─ ADD_NEW (신규 진입)
   ├─ ADD_TO_WINNER (Pyramid)
   ├─ ROTATE (Capital Rotation)
   ├─ TRIM (Partial Exit)
   ├─ KEEP, EXIT, NO_ACTION
   ↓
ExitThesisEngine + SignalDecay (보유 포지션 재평가)
   ↓
Diagnostics (No-Trade Logger / TC Monitor / Execution Quality)
```

## 4. 베이스 4개 모듈

### 4.1 EdgeCalibrator (`v3/strategy/edge_calibrator.py`)

**역할**: `raw_opportunity` → `expected_return_5d` 변환.

**Calibration table 구조**:
```
calibration_table.json
├── version: "v3.3-2026-06-01"
├── lookback_years: 5
├── panel_size: ~25000
├── buckets: {
│     "(decile,)": CalibrationBucket(...),
│     "(decile, regime)": CalibrationBucket(...),
│     "(decile, regime, liquidity_bucket)": CalibrationBucket(...),
│     "global": CalibrationBucket(...),
│   }
```

**Fallback 순서**:
```python
keys = [
    (decile, regime, liquidity_bucket),
    (decile, regime),
    (decile,),
    ("global",),
]
for key in keys:
    if table[key].n >= MIN_BUCKET_N:
        return table[key]
return reject("insufficient_calibration")
```

**제약 (객관 검토 결과)**:
- Level 4 (sector 추가) **사용 금지** — 표본 부족 (550 bucket × 평균 27 row)
- `MIN_BUCKET_N = 30`
- Bear / strong_bull은 5년 lookback에서도 SE 0.5%+ — `calibration_n` 함께 출력하여 다운스트림 감쇠

### 4.2 EdgeEngine (`v3/strategy/edge_engine.py`)

**역할**: `expected_return_5d` → `net_edge_5d`

```python
net_edge_5d = expected_return_5d
            - expected_cost          # commission + spread + impact
            - slippage_buffer        # vol-scaled
            - downside_risk_penalty  # λ × |expected_mae_5d|
```

**Cost model 분해 (v3.2.1의 통합 0.001 → 분해)**:
```yaml
cost_model:
  commission_roundtrip: 0.0002
  spread_estimate: 0.0003
  market_impact_base: 0.0005
  slippage_vol_multiplier: 0.10
  min_slippage_buffer: 0.0010
  max_slippage_buffer: 0.0040
```

**Entry threshold는 분위수에서 도출**:
```python
entry_threshold = panel_top_30pct(net_edge_5d)  # 도출
# 초기 wishful 0.0040은 starting point으로만 사용
```

**Calibration 신뢰도 기반 감쇠**:
```python
if calibration_n < 100:
    net_edge_5d *= 0.5         # 표본 부족 시 보수적
elif calibration_n < 30:
    return BLOCKED
```

### 4.3 AllocationEngine (`v3/strategy/allocation.py`)

**역할**: `net_edge / downside_risk` 기반 sizing.

**기존 VolTargetSizer 대체가 아닌 보완**:
- VolTargetSizer는 vol-target + Half-Kelly 유지
- AllocationEngine은 1차 입력을 confidence가 아닌 `net_edge / |expected_mae|`로 변경
- Sizing curve는 그 위에 적용

```python
edge_risk_ratio = net_edge / max(|expected_mae|, 0.005)
raw_weight     = edge_risk_ratio / Σ edge_risk_ratio_positive
adjusted       = raw_weight × position_scale × correlation_drag × liquidity_multiplier
final          = clamp(adjusted, [min_position_weight, max_single_weight])
```

**Regime exposure budget — leverage 거부, 1.00 cap**:
```yaml
regime_exposure_budget:
  strong_bull:
    max_gross_exposure: 1.00       # NOT 1.20
    target_annual_vol: 0.20
  bull:
    max_gross_exposure: 0.90
    target_annual_vol: 0.18
  neutral:
    max_gross_exposure: 0.70       # 기존 default
    target_annual_vol: 0.15
  caution:
    max_gross_exposure: 0.40
    target_annual_vol: 0.10
  bear:
    max_gross_exposure: 0.00
    target_annual_vol: 0.00
```

### 4.4 ExitThesisEngine (`v3/strategy/exit_thesis.py`)

**역할**: 시간 기반 trigger를 thesis 재평가로 격상.

**현 ExitRules (P1~P5)와 통합 매트릭스**:

| Trigger | 무조건 청산 | 재평가 후 결정 |
|---------|------------|---------------|
| portfolio_stop | ✓ | — |
| dynamic_stop_mae | ✓ | — |
| vol_contraction | ✓ | — |
| profit_take | — | ✓ (Conditional Veto + Partial Exit) |
| max_hold | — | ✓ (Signal Decay 고려) |

**HOLD/REDUCE/ROTATE/EXIT 의사결정**:
```python
if risk_exit_triggered:
    return EXIT
if residual_edge <= 0:
    return EXIT
if best_replacement.net_edge - residual_edge > switching_cost + rotation_margin:
    return ROTATE
if residual_edge < reduce_zone_edge:
    return REDUCE
return HOLD
```

### 5.5 #2 Capital Rotation Engine (`v3/strategy/rotation.py`)

**역할**: 신규 후보 vs 기존 포지션 비교, switching cost 반영.

```python

```

**제약**:
- `min_holding_days_before_rotation: 1`
- `max_rotations_per_month: 4` (현 max_trades_per_month=5와 별도 카운트)
- 낮은 tier가 높은 tier 대체 금지

### 5.6 #3 Conditional Veto 정상화 (`v3/strategy/exit_thesis.py` 내)

**문제 (FOLLOW_UPS 1순위)**: 8h staleness < KR↔US 14h 간격 → 항상 stale → "fire unconditionally" 경로.

**해결 (단계별)**:
1. `refresh_at_session_start: true` — KR 세션 시작 / US 세션 시작 시 즉시 generate_signal
2. `max_signal_staleness_hours: 16` — 14h 간격 + 여유

```python
def conditional_veto(trigger, position):
    if trigger in RISK_BASED:
        return EXIT_FULL
    if signal_stale_age > 16h:
        signal = regenerate_signal(position.ticker)  # session start refresh
    if residual_edge > 0:
        return KEEP
    return EXIT_FULL
```

### 5.8 #6 Signal Decay (`v3/strategy/signal_decay.py`)

**역할**: alpha별 holding period 차등.

```yaml

  alpha_profiles:
```

**dominant_alpha 식별**:

### 5.9 #7 Partial Exit (`v3/strategy/partial_exit.py`)

**의사결정 테이블**:

| 상황 | 행동 |
|------|------|
| TP 도달 + residual_edge 강함 | KEEP |
| TP 도달 + residual_edge 약함 | TRIM 50% |
| max_unrealized +3% 후 -1.5% 하락 + edge 약 | TRIM 또는 EXIT |
| vol_contraction 확인 | EXIT (전량) |
| residual_edge ≤ 0 | EXIT (전량) |

**제약 (페르소나 정합성)**:
- `min_remaining_weight: 0.15` (Phase 25.2 sizer floor와 동일)
- 0.15 × 0.50 = 0.075 < 0.15 → trim 후 잔여가 floor 미만이면 EXIT 전환

### 6.1 V3.2.1 SignalGenerator (유지)

### 6.2 V3.3 BookOptimizer (신규, wrap)

```python
class BookOptimizer:
    """Daily decision engine wrapping SignalGenerator + Edge layer."""

    def __init__(self, signal_gen, edge_calibrator, edge_engine, edge_tier,
                 allocation, exit_thesis, rotation, pyramid, partial_exit,
                 diagnostics, features: FeatureFlags):
        ...

    def decide(self, market_data, positions, state) -> list[BookAction]:
        # 1. Existing SignalGenerator → opportunity rows
        signal = self.signal_gen.generate(...)

        # 2. Edge layer (feature-flagged)
        if self.features.edge_calibrator:
            candidates = self.edge_calibrator.calibrate(signal.opportunity_rows)
        if self.features.edge_engine:
            candidates = self.edge_engine.compute(candidates)
        if self.features.edge_tier:
            candidates = self.edge_tier.assign(candidates)

        # 3. Position-level decisions
        actions = []
        for position in positions:
            if self.features.exit_thesis:
                action = self.exit_thesis.decide(position, candidates)
            else:
                action = legacy_exit(position)
            actions.append(action)

            if self.features.pyramid:
                add = self.pyramid.evaluate(position, candidates)
                if add: actions.append(add)

        # 4. New entries
        if self.features.allocation:
            new_actions = self.allocation.allocate(candidates, regime)
        else:
            new_actions = legacy_size(candidates)
        actions.extend(new_actions)

        # 5. Diagnostics (always read-only)
        self.diagnostics.record(signal, candidates, actions)

        return actions
```
